# Streaming logo sources

- `primevideo-v2.svg` and `hulu-v2.svg`: Simple Icons 5.0.0, used as transparent vector marks.
- `disneyplus-v2.svg`: Wikimedia Commons, `File:Disney Plus logo.svg`.
- `peacock-v2.svg`: Wikimedia Commons, `File:NBCUniversal Peacock Logo (2020–2026).svg`.
- `disneyplus-panel-v1.svg`: vector path geometry from Wikimedia Commons, `File:Disney+ 2024.svg`.
- `max-panel-v1.svg`: vector path geometry from Wikimedia Commons, `File:HBO Max (2025).svg`; white-on-dark usage follows the HBO Max brand portal.
- The other `*-panel-v1.svg` files frame the corresponding repository marks without changing their identities.

These marks remain trademarks of their respective owners and are included only to identify the launcher destinations.
